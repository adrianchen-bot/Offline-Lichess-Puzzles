# Offline-Lichess-Puzzles
A ready-to-go app for Mac that contains all the puzzles in Lichess
Installation:
1. Download the .dmg file
2. Open the file and drag the app into your applications folder
3. Open the app and play!
4. To import more puzzles, simply right click the app in Finder, click "Show Package Contents", then "Contents", then "Resources", then "offline-chess-puzzles", then drag your .csv file into the "puzzles" folder
This app was made using Platypus by sveinbjorn.org and uses offline-chess-puzzles by brianch. Links: https://sveinbjorn.org/platypus, https://github.com/brianch/offline-chess-puzzles
